# CHEM 438 — Notebooks

Google Colab notebooks for CHEM 438 (Intro to Python + Computational Chemistry).

- **`homework/`** — the graded science homeworks, opened from the course app.
- **`practice/`** — extra ungraded practice sets.

**This repo holds only material that has already been released.** Future homeworks
and practice sets are published as the course reaches each topic, so the whole term
isn't available on day one. (The full set is maintained privately and synced here by
`publish_notebooks.py` in the course app.)

Notebooks contain problems only — no answer keys.

Open any notebook in Colab with:
`https://colab.research.google.com/github/jyesselm/chem438-notebooks/blob/main/<path>`
